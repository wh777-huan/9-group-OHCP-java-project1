## 七、常见翻车点（提前避）

| 风险 | 预防 |
|------|------|
| GitHub 连不上，push 失败 | 赛前测一次 push；备选：代码压缩包 + 群文件 |
| 现场 Maven 首次下载依赖卡死 | 赛前 `mvn -o test` 验证离线可用 |
| 中文乱码 | 用 `run.bat`，或 `chcp 65001` |
| 演示时 jar 跑不起来 | 提前 `mvn package`，U 盘备份 jar |
| 全员在写代码没人做 PPT | 演讲手从 T+10 就并行做，不参与编码 |
| 答辩抢答错过 | 指定专人 T+58 起盯群，不看代码 |
