### 2. 大模型密钥

```cmd
set OHCP_LLM_API_KEY=你的key
```

- 建议提前在系统环境变量里设好，别到现场再敲
- 用 DeepSeek：`OHCP_LLM_BASE_URL` 默认就是 `https://api.deepseek.com`，**不要带 `/v1`**
- 用通义：设 `OHCP_LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode`
- **先跑一次真实调用验证 key 有效**，别等答辩时才发现 401

## 七、已知风险

| 风险 | 预防 |
|------|------|
| 现场爬不到网页 | 赛前先把 `knowledge.json` 抓满并提交 |
