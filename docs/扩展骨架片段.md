# 扩展骨架片段（备查）

> 题目形态未定，这里放三种最小可用的扩展写法。
> **不要预先写进主代码**——现场按题目临时取用，否则会变成无用代码，反而扣架构分。
> 三个片段全部零新增依赖，只用 JDK 自带 API。

---

## 一、需要图形界面 → Swing

JDK 自带，无需改 `pom.xml`。适合「做一个可操作的小工具」类题目。

```java
package com.ohcp.project1.ui;

import javax.swing.*;
import java.awt.*;

public class MainWindow extends JFrame {

    private final JTextArea output = new JTextArea(12, 40);
    private final JTextField input = new JTextField(20);

    public MainWindow() {
        super("OHCP 演示");
        setDefaultCloseOperation(EXIT_ON_CLOSE);
        setLayout(new BorderLayout(8, 8));

        JButton run = new JButton("执行");
        run.addActionListener(e -> output.append("你输入了：" + input.getText() + "\n"));

        JPanel top = new JPanel();
        top.add(input);
        top.add(run);

        output.setEditable(false);
        add(top, BorderLayout.NORTH);
        add(new JScrollPane(output), BorderLayout.CENTER);

        pack();
        setLocationRelativeTo(null);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new MainWindow().setVisible(true));
    }
}
```

要点：

- 所有 UI 操作放 `SwingUtilities.invokeLater`，否则答辩演示时偶发卡死
- 耗时任务（爬虫、大模型）必须放后台线程，用 `SwingWorker`，别阻塞 EDT
- 中文显示：`new Font("Microsoft YaHei", Font.PLAIN, 14)` 显式指定，默认字体可能缺字

## 二、需要 Web 接口 → JDK 内置 HttpServer

零依赖。适合「提供 REST 接口供他人调用」类题目。

```java
package com.ohcp.project1.web;

import com.sun.net.httpserver.HttpServer;

import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.nio.charset.StandardCharsets;

public class MiniServer {

    public static void start(int port) throws Exception {
        HttpServer server = HttpServer.create(new InetSocketAddress(port), 0);

        server.createContext("/health", exchange -> {
            byte[] body = "{\"status\":\"ok\"}".getBytes(StandardCharsets.UTF_8);
            exchange.getResponseHeaders().add("Content-Type", "application/json; charset=utf-8");
            exchange.sendResponseHeaders(200, body.length);
            try (OutputStream os = exchange.getResponseBody()) {
                os.write(body);
            }
        });

        server.start();
        System.out.println("http://localhost:" + port + "/health");
    }

    public static void main(String[] args) throws Exception {
        start(8080);
    }
}
```

要点：

- `sendResponseHeaders` 的长度必须是字节数，不是字符数
- 业务异常要转成 4xx/5xx，别让线程抛出去导致连接挂起
- 端口被占用时换 8081，现场别死磕

## 三、需要读写文件 / CSV

题目常给一份数据文件。用 JDK 的 `Files` + `String.split` 即可，别引第三方库。

```java
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public static List<String[]> readCsv(Path path) throws Exception {
    return Files.readAllLines(path, StandardCharsets.UTF_8).stream()
            .filter(line -> !line.isBlank())
            .map(line -> line.split(","))
            .toList();
}
```

要点：

- 明确指定 `StandardCharsets.UTF_8`，Windows 默认 GBK 会读出乱码
- 中文 CSV 常见带 BOM，首行字段名会多一个 `﻿`，用 `line.replace("﻿", "")` 清掉
- 字段内含逗号时 `split(",")` 会错位，题目没保证格式就别硬解析，先看样例

## 四、选择建议

| 题目特征 | 选哪个 | 理由 |
|----------|--------|------|
| 「实现一个 XXX 系统」 | 命令行 + 分层 | 逻辑可测，覆盖率好拿分 |
| 「做一个可视化工具」 | Swing | 零依赖，演示直观 |
| 「提供接口给外部调用」 | 内置 HttpServer | 零依赖，可 `curl` 演示 |
| 「处理给定数据文件」 | 命令行 + 文件读写 | 最少代码路径 |

**通用原则**：60 分钟内，能不加依赖就不加。每多一个依赖，就多一处现场可能构建失败的地方。
